Q. 제공한 c++ 코드를 베릴로그 RTL로 합성하라
-------------------------------------

제공해주신 C++ Clock 함수의 동작(un-timed model)을 베릴로그(Verilog) RTL 코드로 변환한 결과입니다.
하드웨어 설계 특성상, 입력 신호의 변화를 감지하기 위한 시스템 클락(clk)과 리셋(rst_n) 신호를 추가하여 동기식 순차 회로(Synchronous Sequential Circuit)로 구성했습니다.

베릴로그(Verilog) RTL 코드

verilog
module clock_rtl (
    input  wire       clk,      // 시스템 클락
    input  wire       rst_n,    // 비동기 액티브 로우 리셋 (하드웨어 초기화)
    input  wire       clear,    // 시계 초기화 신호 (00:00:00)
    input  wire       start,    // 시계 가동 신호 (1 = 매 클락마다 1초씩 증가)
    output reg  [4:0] hh,       // 시간 출력 (0 ~ 23 표현을 위해 5비트)
    output reg  [5:0] mm,       // 분 출력 (0 ~ 59 표현을 위해 6비트)
    output reg  [5:0] ss        // 초 출력 (0 ~ 59 표현을 위해 6비트)
);

    // C++의 static 변수에 대응하는 내부 레지스터 선언
    reg [4:0] r_hh;
    reg [5:0] r_mm;
    reg [5:0] r_ss;

    // 시계 카운터 로직
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            r_hh <= 5'd0;
            r_mm <= 6'd0;
            r_ss <= 6'd0;
        end
        else if (clear) begin
            r_hh <= 5'd0;
            r_mm <= 6'd0;
            r_ss <= 6'd0;
        end
        else if (start) begin
            if (r_ss == 6'd59) begin
                r_ss <= 6'd0;
                if (r_mm == 6'd59) begin
                    r_mm <= 6'd0;
                    if (r_hh == 5'd23) begin
                        r_hh <= 5'd0;
                    end
                    else begin
                        r_hh <= r_hh + 5'd1;
                    end
                end
                else begin
                    r_mm <= r_mm + 6'd1;
                end
            end
            else begin
                r_ss <= r_ss + 6'd1;
            end
        end
    end

    // 출력 연결 (조합 회로 또는 레지스터 할당)
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            hh <= 5'd0;
            mm <= 6'd0;
            ss <= 6'd0;
        end
        else begin
            hh <= r_hh;
            mm <= r_mm;
            ss <= r_ss;
        end
    end

endmodule
코드를 사용할 때는 주의가 필요합니다.

💡 설계 핵심 요약

• 비트 폭(Bit Width) 최적화: unsigned char 자료형을 하드웨어 자원에 맞게 각각 시(hh = 5비트), 분/초(mm, ss = 6비트)로 최적화하여 합성했습니다.
• 우선순위 반영: C++ 코드의 if (clear) ... else if (start) 조건문 구조를 그대로 반영하여 clear 신호가 start보다 높은 우선순위를 갖도록 구현했습니다.
• 동기화 처리: C++ 함수의 출력 대입 연산 수식을 하드웨어의 클락 상승 엣지(posedge clk)에 동기화되는 레지스터 출력 방식으로 안정화했습니다.
작성된 RTL 코드를 검증하기 위한 테스트벤치(Testbench) 코드가 필요하시거나, 1초를 만들어내기 위한 클락 분주기(Clock Divider) 로직 추가를 원하시면 말씀해 주세요.
